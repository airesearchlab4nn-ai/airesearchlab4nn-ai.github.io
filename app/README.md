# /app/ — Average Down Risk Simulator, web version (BLD-WEB-APP-PUBLIC, 18 Nov 2026)
Address: https://airesearchlab4nn-ai.github.io/app/ (GitHub Pages, same repository as the site; own domain later — MAIN).

Files (all generated by `apps/lab_site/build_app_page.py` from `apps/average_down/dist` after the `app_check` job; do not edit index.html by hand):
- index.html — the app in one file (bundle inlined), title/description, og:image, favicon, counters. Same file as apps/average_down/web_single/index.html.
- og.png — share card 1200×630 (app default: S&P 500, $1,000, 3×, buy more every −5% → 38 of 100, about 5½ months).
- config.js — OWNER: GoatCounter code (no cookies). Empty = nothing is sent. The builder never overwrites it.
- count.js — copy of check/count.js (pixel, no cookies, no IP, device type only).
- icon.png — favicon (= site/assets/icon.png).

Counted events (GoatCounter): page view `/app` (opened), `app_result-<ios|android|desktop>` (reached the result), `app_share-<device>` (pressed Share).
Share: on phones — the system share sheet; on desktop — the text is copied («Copied — paste it anywhere.»). Text ends with «Try it: https://airesearchlab4nn-ai.github.io/app/».

Upload (owner): copy this whole folder to `app/` in the site repository; replace the site's index.html (link «Try it in your browser»). The footer of check/index.html also links here (goes up with check/ on launch).
Rebuild after app changes: job `app_check` → `PYTHONPATH=.vm_pylib python3 apps/lab_site/build_app_page.py`.
